# Bili Favorites Classifier

一个用于读取 Bilibili 用户公开收藏夹、抓取视频标签并进行分类展示的桌面工具。

当前版本：`v1.6.0`

## 功能

- 输入 Bilibili 用户 ID，读取其公开收藏夹中的视频 BV 号列表
- 支持两阶段抓取：先读取收藏夹列表，再选择需要分类的收藏夹后抓取视频和标签详情
- 自动抓取视频标签与视频分区
- 支持在界面中调整请求间隔和标签抓取并发数，降低触发 B 站风控的概率
- 支持本地视频元数据缓存，重复运行或中断后重试时会复用已抓取的标签/分区信息
- 默认模式下按照 Bilibili 视频分区直接分类
- 自定义模式下支持不限数量的类别，每个类别可填写多个关键 tag
- 支持保存和读取自定义分类规则，下次启动可自动恢复已保存规则
- 可调整自定义分类规则顺序；同一视频命中多个规则时，按规则自上而下进入首次命中的分类
- 图形界面展示分类结果，双击视频即可在浏览器打开对应页面
- 使用更现代化的桌面界面布局，分类、账号同步和结果浏览分区更清晰
- 支持右键将视频移动到其他分类
- 支持粘贴登录 Cookie，检测当前登录账号
- 支持将分类结果同步到 B 站收藏夹，可选择“复制”或“移动”
- 支持将分类结果导出为 `JSON` 或 `CSV`
- 支持通过 `PyInstaller` 打包为 Windows `exe`

## 运行方式

运行`run.bat`

## 打包为 exe

项目根目录已经提供：

- `build_exe.bat`
- `BiliFavoritesClassifier.spec`

在 Windows 下直接双击或在终端运行：

```bat
build_exe.bat
```

构建完成后，生成文件位于：

```text
dist\BiliFavoritesClassifier.exe
```

说明：

- 打包脚本会自动创建独立的构建虚拟环境 `.venv-build`，不会依赖你当前全局 Python 的打包环境。
- 若首次构建较慢，通常是正常现象，因为需要下载安装打包依赖。

## 使用说明

1. 在窗口顶部输入 Bilibili 用户 ID。
2. 选择“默认分类”或“自定义分类”。
3. 点击“获取收藏夹”，等待公开收藏夹列表加载完成。
4. 在“收藏夹选择”页勾选需要抓取和分类的收藏夹。
5. 如果使用自定义分类，可通过“新增分类”持续添加类别，并填写类别名称与关键 tag；使用“上移/下移”调整匹配优先级。
6. 可在“请求节奏”页调整请求间隔和标签并发数；遇到 HTTP 412/429 时建议增加间隔、降低并发。9k 级别收藏夹建议使用 `1.00` 秒间隔和 `1` 并发重试。
7. 点击“抓取并分类”。
8. 结果会在右侧树形表格中展示，双击某条视频即可打开 Bilibili 页面。
9. 右键某条视频可将其移动到其他分类。
10. 点击“保存结果”可导出本地文件。
11. 若要把分类结果同步到 B 站，在左侧“账号同步到 B 站”区域粘贴完整 Cookie。
12. 点击“检测登录”确认当前账号。
13. 选择“复制到分类收藏夹”或“移动到分类收藏夹”。
14. 选择新建收藏夹的公开/私密属性，然后点击“应用分类结果到 B 站”。

## 收藏夹选择

- “获取收藏夹”只读取目标 UID 的公开收藏夹列表，不会立刻抓取每个视频详情。
- 在“收藏夹选择”页可全选、清空或单独勾选收藏夹。
- “抓取并分类”只会处理已勾选的收藏夹，适合先对大收藏夹分批分类。

## 自定义分类规则

- 每一行代表一个类别，行顺序就是匹配优先级。
- 左侧填写类别名，右侧填写关键 tag，关键词用英文逗号分隔。
- 规则主要基于视频 tag 做匹配，支持相同 tag 与相近 tag 的匹配。
- 自定义分类会自上而下匹配规则；同一个视频若符合多个类别，只会进入第一个命中的类别。
- 未命中任何类别的视频会统一进入“未分类”。
- 点击“保存规则”会将当前自定义规则保存到本机用户配置目录；点击“读取规则”可恢复保存过的规则，启动时也会自动尝试读取。

## 大收藏夹与 HTTP 412

- 工具会按分类模式减少请求：默认分区分类只补充分区信息，自定义标签分类只抓取标签。
- 已抓取的视频元数据会缓存到本机用户配置目录，重试时会跳过缓存命中的视频。
- 如果仍触发 HTTP 412/429，请在“请求节奏”页调到 `1.00` 秒间隔、`1` 并发，并分时段重试；B 站风控解除前无法保证一次性完成全部 9k 视频。

## 同步到 B 站收藏夹

- `复制到分类收藏夹`：更安全，会把视频复制到新分类收藏夹中，原收藏夹内容不动。
- `移动到分类收藏夹`：会把视频从原收藏夹迁移到分类收藏夹中。
- 程序仍会阻止存在重复归类冲突的旧结果执行“移动”，避免同一视频被迁移多次。
- 当前版本仅支持把结果同步回“与已分类 UID 相同”的登录账号，避免误操作到其他账号。

## 如何获取 Cookie

1. 打开浏览器并登录目标 B 站账号。
2. 访问 `https://www.bilibili.com`。
3. 按 `F12` 打开开发者工具，切到 `Network` 面板并刷新页面。
4. 点开任意一个发往 `bilibili.com` 的请求，在 `Request Headers` 中找到 `Cookie`。
5. 复制整段 `Cookie` 字符串，粘贴到本工具。

最低需要的关键字段：

- `SESSDATA`
- `bili_jct`

安全提醒：

- Cookie 等同于登录态，不要发给别人。
- 建议只在本地临时粘贴使用，用完后清空。

## 说明

- 本项目使用 Bilibili 公共接口获取公开收藏夹和标签数据；如果目标用户没有公开收藏夹，工具会直接提示。
- 默认分区分类依赖 Bilibili 返回的 `tid/tid_v2` 信息；个别视频若接口未返回完整分区名，会回退到内置分区映射或分区编号显示。
- 收藏夹写操作依赖登录 Cookie 与 `bili_jct`，也依赖 Bilibili 当前接口规则；若 B 站后续调整接口，可能需要同步更新。
- 结果依赖公开数据和接口可访问性，若 Bilibili 后续调整接口，可能需要同步更新。
